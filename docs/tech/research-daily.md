# 科研日报

一个把「每天读文献」这件事完全交给 AI 的自动化系统。每天自动抓取光电、AI、半导体等领域的顶刊与 arXiv 新论文，由大模型按我的知识水平与口味做多维量化筛选，挑出最值得读的一两篇，生成中文深度解读，再通过飞书卡片推送。

在线访问：[科研日报](http://114.55.177.240:8000/)。

起因是 GLM 5.3 flash 出来，token 用不完了，周末又赠了三亿 token，于是在尝试做个项目。

但感觉在慢慢降智和变慢，整体可能也不算完全达到我想要的效果，但又描述不出来哪里有欠缺。或者说，可能我也不知道我想要什么。

部署在了阿里云的一个服务器上，但服务器十二月就到期了，到时候可能考虑直接放弃或迁移，续费太贵。
