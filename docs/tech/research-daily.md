# 科研日报

一个把「每天读文献」这件事完全交给 AI 的自动化系统。阿里云服务器每天自动抓取光电、AI、半导体等领域的顶刊与 arXiv 新论文，由大模型按我的知识水平与口味做多维量化筛选，挑出最值得读的一两篇，生成硬性不少于一万字的中文深度解读——Introduction 全文照抄、逐段白话讲解、附原论文配图——再通过飞书卡片推送，并在网站上永久归档。

在线访问：[科研日报](http://114.55.177.240:8000/)。

## 网站上有什么

- **日报**：每天的论文深读归档，每篇展示机器给的四维评分（相关度、重要性、可读性、新颖性），还可以就这篇论文向 AI 提问；
- **导师日报**：每天认识一位光电学院导师——基本盘、研究方向、招牌论文精读加知识专题，17 位导师轮换循环；
- **术语库**：解读里出现的专业术语的中文释义；
- **选题机制**：论文筛选的打分权重与规则全部公开在页面上，每周日还会根据我的打分反馈自动校准；
- **运行台**：各环节的模型分工、运行历史与一键换模型的运维面板。

整套系统最有意思的地方是反馈闭环：我读完每篇解读后按同样四个维度打分留言，反馈每周自动回灌给筛选器，让选题越推越准。项目本身也是一次完整的 Vibe Coding 实践——需求写成文档，代码全部由 AI 会话实现，抓取、解读、推送、网站、安全加固一路落地在一台阿里云服务器上。
