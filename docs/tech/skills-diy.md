# SKILLS DIY

用 AI 干活这两年，我攒下了一批自己写的 skills——就是给 AI 助手看的"技能包"：一个说明书加几个脚本，AI 读了就知道什么时候该用它、怎么一步步干。超星课件下载、大物实验报告、问卷星建卷、邮箱公文草稿、图床上传、CC98 论坛爬读、微信公众号归档……基本都是校园生活里反复出现的体力活，写一次 skill，以后一句话就能让 AI 代劳。

现在我把其中比较成型的 13 个整理开源了出来：

> **仓库地址：<https://github.com/aNewfolder/zcode-skills>**

## 先把丑话说在前面

- **这些 skills 全部由 AI 辅助编写**（ZCode + GLM）。我负责提需求、测试、迭代，代码几乎一行不是人手写的。
- **不保证及时更新，不保证质量。**它们深度依赖各平台的网页接口，平台一改版就可能失效，我也未必有空修。
- 但凡放上来的，**一定是我自己用过、并且觉得好用有帮助的**，不是写着玩的 demo。
- 仓库里不含任何账号凭据，需要登录的 skill 都在你本机配置自己的账号，详见每个 skill 的 README。

## 都有些什么

**课程与作业**

- **chaoxing-courseware** — 超星学习通课件下载：按章节爬取课程文件（pptx / docx / pdf），账号密码登录后 Cookie 持久化，之后一句话下载整章课件
- **gctrain-homework** — 工程训练平台每周预习作业自动取题、答题、提交（仅校园网可达）
- **circuit-lab-report** — 《电子电路基础及实验》实验报告：XeLaTeX 版式复刻课程 Word 模板，处理数据、出规范报告
- **physics-lab-report** — 《大学物理实验》预习报告与实验报告：严格按课程的不确定度评定与有效数字规范，自动下载讲义、传图、排版

**校园信息**

- **cc98-crawler** — CC98 论坛帖子搜索、正文与附件抓取到本地，支持全文检索和按兴趣推送（需校园网）
- **cc98-viewer** — 不在校网时经 WebVPN 实时看 98 新帖，页内阅读器直接读帖

**文档与邮件**

- **kdocs** — 金山文档 / WPS 云文档操作：云端建表写入、读单元格、分享设置，配浏览器自动化兜底
- **mail163-draft** — 163 邮箱公文排版存草稿：仿宋正文、Times New Roman 西文、首行缩进、署名日期右对齐，一键排好存进草稿箱（绝不自动发送）
- **zjuem-mail-draft** — 浙大邮箱同款公文草稿工具，统一认证 API 直连

**内容与工具**

- **wechat-article-reader** — 微信公众号推文完整归档成 Markdown，图片视频音频全部本地化，还能免登录读一个公众号的最新推送生成日报
- **picgo-image-upload** — 调本机 PicGo 图床上传图片拿外链，写笔记插图的默认通道
- **solidworks-reader** — 免开软件只读提取 SolidWorks 零件 / 装配体 / 工程图数据，输出 JSON
- **wjx-survey** — 问卷星全流程：70 多种题型建卷、发布、答卷导出、统计报表

## 怎么用起来

skills 是一种通用的 agent 扩展格式（ZCode、Claude Code 等都兼容）：克隆仓库，把你想要的那个目录整个复制进 AI 助手的技能目录，装上依赖、配好你自己的账号就行。每个 skill 目录里都有一份 README，依赖清单、要配置什么、常用命令、注意事项都写好了，人和 AI 都能照着做——我连"读者是 AI"这件事都考虑进去了，你甚至可以让你的 AI 助手自己去读 README 完成部署。

如果你用出了问题，或者想交流怎么写自己的 skill，欢迎到仓库提 issue，也欢迎在页面底部的留言板聊聊。
