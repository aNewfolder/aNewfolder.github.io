# Eighteen

To WZY:

Hope this letter finds you, and finds you well.

于是，就成年了。

真正经历的时候，不过是如此波澜不惊，几年前，几月前，所有那些求而不得，所有那些心血来潮，纷纷扰扰，不久后淡出，或遗忘。

当然有些事不会忘，每年此时总会收到三四封信和两三件小礼物，国庆合唱比赛的歌曲定成了《夜空中最亮的星》，回老家路上又一次听到《起风了》，也会有东西写给自己，哪怕没有所谓的成人礼。

回望十八年的时光荏苒，有太多事情值得感激。一点点补完了从2023年到现在的每一篇拾遗，近百万字，见多了算不上合格的父母，庆幸原生家庭为自己留下的珍贵的童年经历。

其实也调取不出太多印象极深的记忆，更多是些长此以往的默默的悦纳与奉献。小学初中不理解也写不出每时每刻的情绪稳定有多难，现在大概也写不出，但后来发现自己即使常常自我提醒在许多语境下依旧做不到。同样是疏远些许才觉察自己面对太过亲近的人也难逃不加思考的干涉，还需慢慢成长与锤炼。

也慢慢把父母当作鲜活的人去看，会有自己的性格特点，自己的局限。曾经的父母是整个世界的准绳，但奥林匹斯山上诸神依旧无法登上真正的神坛，于是尝试去推演那些被忽视的因果，进而开始学着去包容与接受。

无论是给自己还是他人，生日贺信从初中到现在也写过近二十篇。真诚是永恒的主题，但依然能够觉察文风的改变。从英语到汉语的缓慢转变，一段时间热衷于堆砌喜欢的名言试图证明观点，或者讲，把认可的名言作为观点。后来发现名言无穷无尽，有些留下了印记，有些没有，引用一句话不过是因为自己尚未企及，经历本身才算得上自己的东西。

但依旧缺乏足够的内在坚韧性和自信心，疑虑自己的反抗不过是稚嫩，疑虑辛辣锋锐的文字背后不是专一的行事准则而不过是刻意寻觅独异。努力为自己心目中的合理去发声与实践，拒绝接受高高在上盛气凌人而又匮乏逻辑的论辩，欣然接受认可的主流，然后选择性地对那些不认可的部分讲主流不代表正确。向自己许诺不后悔任何选择，便是仅剩的底气。

因此信念是享受当下，放眼未来。三年前的现在已经看清初中的局限放眼高考，而三年后的今天自应把目光投向高考后的假期，大学与更远的未来。准备工作是必需的，不想耽搁任何假期时间，算是在有了清晰的向往后首次，或许是为数不多的一次甚至几十年的时间里唯一一次，可以完全掌控自己生活的机会，这件事情本身，已经足够让人心潮澎湃。

具体早有打算，在一年多的不断构思与补充中臻于完善，时间不够的观点不是空喊，而是出自一次次的精确计算。高一的那篇《向光而行》是蓝本，很难想象早在那时便能如此完备地表达出来。

因此不会接受任何形式的绑架与强迫，高中生活停留在2025年6月10日下午12:30，没有留恋，只剩怀念，不会去培训，也不会为强基做任何额外准备。

因此对成绩看淡，分数高低不会影响理想的实现。未入高三时早已坚定拒绝高三，既然社会现实难以改变，学校理念一以贯之，那么丰富、愉悦、松弛地度过这一年也算是无声地捍卫心目中的理所当然。

因此拒绝放空一切全情投入，滞钝思想从来不是自己的选择，也没有任何掣肘天地的抱负和成为时代启明星的宏愿，去年的生日朋友写“及时行乐是亘古不变的真理”与“更重要的是快乐与自洽”，深以为然。

因此更要把握仅剩的一年，有心去做那些大概毕业后很难有大量时间再去触碰的事情，比如《红楼梦》诗词曲赋的背诵，比如与身边的同学长期共处的机会，比如。

因此重申自己的承诺，我的答案永远一样，我永不后悔。

关于更远的未来，也想过许多。一次次发觉认知的局限，于是选择接受不确定性的到来。十年的确很长，的确能做成许多事，但凭着当下的眼界又能立下什么切实的盟约，不过是些微无边际的构想。

考虑过与父母的相处方式，有人讲所谓成长就是与父母渐渐疏远的过程，讲不要背负他人的命运，哪怕是最亲近的人，可是在分享、关心与干涉之间不过是极为模糊的界限。

考虑过未来的生活方式，赶ddl到凌晨的例子屡见不鲜，朝九晚五的生活是一些人的厌恶，更是一些人的求而不得。既要拿着一份可观的薪水，还想有更多时间给自己，不可否认的确存在，会不会属于自己。

考虑过恋爱结婚生子，觉察内心的一丝抗拒，艰巨的任务，不想面对种种矛盾与不悦，不想不负责任地匆匆承担起一个生命的成长之路，又没有足够的勇气与毅力去拒绝这一切。

考虑过全新的社会面貌，基本实现现代化，科幻小说里的构想能实现多少，困扰人类数千年的重复性劳动有多少会智能化自动化，20后长大，10后崭露头角，00后的时代，新高考的改革会如何，还有多少人谈论着躺平和内卷。

考虑过更多人的老去，更多事物的到来，潮流的变迁，手机电脑又更新了几代，当下的朋友还剩多少，每年还会发出几封信件，钢琴是否还在弹，0731的文章是否还在写，会在哪个城市，会扭转多少当下的倔强与理所当然。

但此刻，今天，愿你庆贺自己的成年。

然后把一切交给时间。

2024.10.10
