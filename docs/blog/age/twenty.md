# Twenty
Not a teen anymore.

---

度过了大概日后回忆时会颇为怀念的一年，没有太多的波折或压力，会比潜意识里的预期更加忙碌，但发现自己并不排斥这种充实。在不同的地方认识了许多很好的朋友，许多欢悦与感动，也在逐渐尝试把想做的事情从仪式变成一种日常，或许可以有一些底气去讲没有让曾经的自己失望。

又好像依旧是曾经的样子，曾经的习惯，曾经的性格，曾经的烦恼，想做的事情依旧是 16 岁写下的那几项，依旧是个小孩的模样。

但会觉得时代在变化，氛围在变化，许多习以为常的因果逻辑关系不再成立，整个环境呈现出的趋势是愈加迎合特定的评价体系。试图去思考有关主体性和确定性的问题但发现没有完整的时间也没有足够的动力，从这个角度看又很难判断大学与高中哪段日子更加荒芜贫瘠。

当然大多时候都很开心，美好与欢悦的丰富让脆弱、戒断与幻灭感的触发频率大大降低，整体去审视这一年也少有什么深刻的负面记忆。快乐和自洽自然是意义本身，只是不再像 16 岁那样明确地信奉“幸福是对重复的渴望”，不再那么坚定地在座右铭一栏写下“自己满溢，自己降露，自己做焦枯原野上的雨”。

因为疏于记录其实并没有留下多少日常心绪的流动，博客更多在描述事件，也不知道能够坚持更新几个月或几年。能够记住的大概有东三二楼文化长廊的沙发，整个春夏学期的中午几乎都会到那里看十几分钟的书，然后午休；五一听了一场音乐会后迷上《加勒比海盗》的主题曲，自此开始高频率约琴房，虽然练了五个多月到现在还是错误百出；五个多小时一口气结束八月入学带来的混血王子，熟悉的史诗感的幻灭，读得更细腻，更具体；第一个期末周集中在青四或主图，第二个期末周意识到补天补不上索性开始探索校园打一枪换一个地方，尧坤楼、艺博馆、地科学院、物理学院、文学院、公管学院、心理系、化学院，当时循环听的《五十年之后》大概要再过几个月再尝试去伴奏；暑假过的比高考后更加贴近理想，没有再接家教，不再需要每天花一两个小时练车考驾照，彻底抛弃了六年以来用假期提前预习的任务，每天读书，弹琴，学乒乓球，跟爸爸去小区实战，看欧洲大满贯，偶尔打打架子鼓，写完了课程总结，做出来了自己的博客网站；第三次读完《红楼梦》，再去重读蒋勋，热毒与冷香丸，反思自己有没有过度热衷于一些东西，是否少了一些理想主义；八月中旬学长组返校之后又约了几场球，打了人生第一场开球网六局全败于是放弃这个想法，六节课突击完蛙泳直接去上游泳中级班，虽然游的依旧很烂；经过许多次触动的铺垫看完《海上钢琴师》终于决定开始系统学即兴，找了老师开始恶补和弦乐理知识，或许哪天也能即兴弹出好听的旋律；也上到了几门真正喜欢的课，春夏 Dominic 的英语辩论基本变成了聊天，陈艳华老师的英语演讲在国庆前一天花两个小时看了一部完整的《至暗时刻》，又一次见到英国议会，与英语辩论遥相呼应，极尽心思补选上的《中国现代文学经典选读》完全没有让自己失望，是能够专心完整听完三节课的课堂；去年此时买的西装越穿越熟练，连续两年忘了预定生日面，大部分课变成了西教于是往返宿舍更加方便，在紫金港的最后一年。大一定下的的主线是体验，体验尽可能多的大学能够提供的机会与资源，那么大二是什么，一直没有得到一个明确的答案，今天我会说或许是珍惜，珍惜与紫金港，与紫金港所承载的人、事、物，所承载的习惯、缘分与瞬间，同处的最后一年，许多连结终究会慢慢黯淡于物理距离的拉远，所以用一年时间去执迷、眷恋、牵挂、执着，在离开之前，去认真地告别。

也给明年的自己留三个心愿吧，是暑假结束的前一天写下的：

1. 好好吃饭，好好休息。
2. 还是那句，不要沉溺于虚拟世界，在完整绝对地拥有手机的同时，保留一份敏感性与对现实的观照，把更多时间花在有意义的事情、让自己快乐的事情，以及二者的交集上面。
3. 清醒。明确自己此刻的状态，明确一段时间内的主线，更具体一点，明确自己想要什么，以及如何获得自己想要的东西。清醒地辨识出自己此刻的余念，然后明确其在不同阶段的意义。清醒地接触和看待每一个具体的人，不妄加批判，不迷失自我。

产出过程异常艰难的一篇文章，过去的风格更倾向于国庆期间基本写完，但今年构思许久写写删删依旧找不到合适的逻辑去串联，到今天概统课上终于完成大半，九点十五下课后收尾到现在，也不算晚。

最后，欢迎来到二十岁。
