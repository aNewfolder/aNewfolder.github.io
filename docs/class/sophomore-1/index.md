秋学期结束简单总结一下。

经过半个学期的实践感觉这种手写笔记+听课的模式并不是非常适合自己。初衷是通过更新网站的任务驱动自己认真听课认真记笔记，但可能确实算不上听课型选手，对知识的吸收率非常低，下个学期的打算可能是完全放弃听课，通过智云的讲义+教材 cover 掉老师讲的东西，那么可能课程笔记里面也只能放一些期末复习整理的资料了。

认真听课的愿望也实现的一般，前几周还能够认真听，后面知识变难慢慢有些听不懂，课下也没有去补，上课也就听不进去了。希望上课写作业是一个能够把自己的 attention 从手机上抢回来的方式。

一个学期刚好用完了一个笔记本，后面更多可能就是用它来写作业了。

最后希望期中周补天顺利。
