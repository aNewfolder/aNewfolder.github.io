# 花之舞

很喜欢的成品曲。

难度不小，右手重复性很高但难点在于加速，左手不断在变，龟速都还没弹利索但最后理论要跟右手同样速度...

再加上人生第一次弹的五个升号的曲子，绝不浪费任何一个黑键#&……￥@

不过真的很好听啊。
