# 诀别书

被舍友推荐，然后莫名其妙越听越喜欢。

从青岛回家之后准备开始练，这两天在疯狂听。

这首曲子的特点是没有一个官方谱子，因为邓垚老师每次弹都会即兴改一些内容。网上我找到了两种主流制谱，更喜欢下面放的这种，虽然似乎不是最常见的版本，但是更喜欢它的节奏掌控，以及它没有另一个版本那么恐怖的琶音（）

补：没有想象中那么难但是间奏部分也没有想象中那么简单，目前预计正式开学前能练出来。
