# 游泳

大二上学期作为一个基本零基础的游泳小白直接选了游泳（中级）所以打算暑假先预习一下蛙泳。

游泳真难。

- Lesson 1：学会了憋气，尝试漂浮，学会了收翻蹬夹（2026.6.30）
- Lesson 2：尝试蹬腿+换气，但是需要借助三种不知道叫啥的浮板...（2026.7.13）
- Lesson 3：返校了！复习蹬腿，学习换气，鲨鱼板依旧在用，浮力棒因为都被占用所以没有用，绑了三块背漂，到后期减了一块变成了两块，已经基本能游起来，虽然还是会沉。（2026.8.16）
- Lesson 4：两块背漂变成了一块，不过游一趟好累啊，教练说还是不够放松。（2026.8.20）
- Lesson 5：一块背漂游了两圈就拆了，不带背漂基本能游起来了，然后又学习了划手，先是浮力棒+一块背漂，然后把浮力棒拆了，最后把背漂拆了，但是还是会沉，需要划一次手蹬两下腿。水感在明显变好，虽然中间也没练习但是每节课去上课就是会有进步，非常有成就感。（2026.8.25）
- Lesson 6：前两个 20 米没游起来，很快就找到感觉了。后期慢慢能够只蹬一次腿，越来越从容了。后半节课尝试了抬头蛙，大概是还没有完全掌握放松的能力，总之感觉非常累。下节课可以开自由泳了。（2026.8.26）

## 蛙泳
- 憋气：用嘴吸一口气，可以鼓着腮帮子，这样就不太会吐气了。
- 蹬腿：收翻蹬夹，蹬的时候一定勾着脚背，尽可能踹的角度大一些，然后夹回来绷脚背。
- 蹬腿+换气：憋气漂浮状态蹬腿，随后滑行 3 秒左右，滑行过程中开始鼻子吐气，然后仰脖子吐水一口然后迅速吸一口气**迅速把头埋下去**。上的过程可以慢但下的过程要快，因为会下沉，然后趁着还没沉下去抓紧蹬腿，形成连续过程。不用蹬的很快，角度大即可，整个人放松。抬头是仰脖子，肩膀不要出来不然会沉。
- 划手：外翻、抱水、夹肘、伸手。外翻不用太大，1.5 倍肩宽左右即可，抱水大臂不动小臂垂直往后划，不用划到身侧，胸前夹肘伸手。保持手臂在水下，可以略向下。
- 蹬腿+换气+划手：前进先蹬腿，抬头的同时外翻，给一个向下的力把头抬起来。伸手的同时收腿，然后蹬出去。
- 抬头蛙：正常蹬腿，划手在水面上滑就可以，不需要抱水了。蹬一次腿，划一次手，频率会比正常游更快。
