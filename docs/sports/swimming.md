# 游泳

大二上学期作为一个基本零基础的游泳小白直接选了游泳（中级）所以打算暑假先预习一下蛙泳。

游泳真难。

- Lesson 1：学会了憋气，尝试漂浮，学会了收翻蹬夹（2026.6.30）
- Lesson 2：尝试蹬腿+换气，但是需要借助三种不知道叫啥的浮板...（2026.7.13）
- Lesson 3：返校了！复习蹬腿，学习换气，鲨鱼板依旧在用，浮力棒因为都被占用所以没有用，绑了三块背漂，到后期减了一块变成了两块，已经基本能游起来，虽然还是会沉。（2026.8.16）

## 蛙泳
- 憋气：用嘴吸一口气，可以鼓着腮帮子，这样就不太会吐气了。
- 蹬腿：收翻蹬夹，蹬的时候一定勾着脚背，尽可能踹的角度大一些，然后夹回来绷脚背。
- 蹬腿+换气：憋气漂浮状态蹬腿，随后滑行 3 秒左右，滑行过程中开始鼻子吐气，然后仰脖子吐水一口然后迅速吸一口气迅速把头埋下去。上的过程可以慢但下的过程要快，因为会下沉，然后趁着还没沉下去抓紧蹬腿，形成连续过程。
