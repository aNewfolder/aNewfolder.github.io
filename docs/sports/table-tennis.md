# 乒乓球

高考后开始培养的爱好。简单写一些需要注意的点。
最大的问题就是身体容易僵在原地只用手臂发力，要用身体的力量，每个球都有收紧再放开的爆发力。

## 接球

- 正手：蹬腿转腰，用身体的力量，用脚找球。**不要拉手太大，这是思维方式的问题，要养成习惯正手先转腰，腿先动**
- 反手：以胳膊肘为支点，小臂向外打，不要敲，尽可能拍头朝左，注意压板，可以上步提前去击球，不用等球弹高
- 正手短：上右腿，球拍贴着台面直线伸出去，向上收，打出力量。把整个小臂加上手腕都放低，不用锁着，胳膊舒展
- 反手短：上右腿，先俯身拍头朝左等球，要有等的动作
- 侧身：侧过来之后直接把重心放在右腿上，等球，蹬腿转腰
- 反手出台：垫步整个人到左边，同反手短
- 扣杀：右手往后上方等球，垫步，在上方往里收
- 反手撕：在反手动作基础上准备时拍头朝下，球拍前部触球，手腕的力量，极致的压板，基本是平着触球，上升期最高点触球
- 反手搓球：低高低（胳膊肘放低，手腕抬高，拍头放低），先上右脚俯身等球，拍子放到球前面，离近一点，然后再用身体的力量向前向下，往下的要多一些，不要停在一半
- 正手搓球：胳膊肘夹紧身体，垫步左腿右腿一起上，俯身，用身体的力量，离球很近的地方等球，接触球的瞬间向前向下，不需要刻意砍
- 正手拉下旋：极致的左前右后，重心放在右腿，左肩转过去向右，大臂放松，手臂自然下垂，球拍放低，外侧向上向前画圆收回来，拍头向下，手腕内钩往对方正手位打，蹬腿发力，把身体转正，压板，收小臂，触球瞬间食指发力向上，大臂不要抬，抬小臂
- 正手挑打：针对下旋球，较高/较长直接攻球姿势瞬间向前向上发力，注意加上向上，较短可以先搓球姿势等球，触球瞬间迅速手腕内翻，等球的时候手必须放在球下面
- 反手拧拉：尽可能让身体与球接近平行，球越靠左越好接，胳膊肘架高撑住，刻意架住胳膊肘，只动小臂，从拍头朝下向外打，小臂要出去，先上右脚俯身在球前面等球，必须有等球的动作，弹起来较低时直接拧出去，不要等球弹高，**等球的时候离球要非常近**
- 反手拉下旋：拍头下压，朝向 7 点方向，胳膊往下放，核心收紧下蹲，腰腹找球，起来的一瞬间，小臂往前挥，胳膊要放到位

## 接发球

- 拍头朝前，俯身向前趴，观察对方出手时拍面与球的接触情况
- 接侧上旋：拍面下压往对方击球同侧歪，例如对方击打球的左侧，自己也击打球的左侧。更实用的方法是在打飞一两个球之后慢慢找角度，不过前提是对手只会发一种侧旋。一般来说瞄着中间打，顶多会歪到一边
- 接正手短未知侧下旋：手腕往外拧，摆正手短的姿势，不容易吃球

## 发球

- 正手发下旋：腰基本抵在球台左边角，左前右后，中指抵在胶皮与底板交界处，拇指食指握拍，要有手腕动作。俯身趴低一点，左手略向前放，左右左重心转换，上抛时两手同时向上，向后引手，等球落低再击球，用拍的前部触球，往腰间砍，把球打出去之后再起身，上左腿恢复正常站位，发球要果断，然后迅速把手型还原，注意步伐移动不要站死
- 正手发上旋：前置动作与下旋完全一致，等球落低触球前的一刹那把拍面翻过来发急奔长球，冲着两个角和底线发，重点在于打对手一个措手不及
